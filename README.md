# 預金キャンペーン市場インテリジェンス（Webサイト2）

既存の `webサイト` とは独立した分析版です。既存版のファイルは変更しません。

## 画面

- 市場概況
- 金融機関分析
- 競合比較
- 満期管理
- 市場トレンド
- データ検索

## データ

- `campaign_all.json`：キャンペーン明細
- `r1_data/base_rate_history.json`：通常金利履歴
- `tibor_monthly.json`：月次TIBOR

満期管理は、実際の預入日・販売実績ではなく、「キャンペーン開始日＋預入年限」で計算した開始日起算の推計満期日です。複数年限がある場合は、年限ごとに別の満期日として集計します。

## 起動

`run_web_windows.bat` を実行し、ブラウザーで `http://127.0.0.1:8766/` を開きます。

全国巡回後に既存WebのJSONが更新された場合は、`sync_data_from_web1.bat` を実行すると、分析版の3種類のJSONも最新化できます。
